# 项目计划与里程碑

> 文档编号：PM-LeadOps-001　　版本：v1.0　　日期：2026-10-04　　负责人：张路

## 1. 项目范围

- 覆盖：潜客运营全链路（数据接入 → OneID → 画像 → 模型 → 圈选 → 旅程触达 → 派单 → BI）。
- 不覆盖：售后维保、二手车交易、整车 OTA。

## 2. 里程碑

| 阶段 | 时间 | 目标 | 交付 |
|---|---|---|---|
| M0 启动 | W0 | 立项、团队到位、环境就绪 | 项目章程、人员到位、云资源申请 |
| M1 MVP | W1–W8 | 核心闭环可用 | OneID + 基础画像 + 规则圈选 + 短信/企微触达 + 简单看板 |
| M2 智能化 | W9–W16 | 模型与自动化 | 意向评分、A/B 实验、旅程编排、Doris Bitmap 优化 |
| M3 扩量 | W17–W24 | 投放与归因 | Lookalike、推荐召回、MTA、SDR 智能派单、合规 |
| M4 持续迭代 | W25+ | 深度优化 | 深度模型、AutoML、实时特征、多业态联动 |

## 4. 第 2 期（W9–W16）

- 意向评分模型 v1（LightGBM）；
- MLflow + Triton 推理；
- A/B 实验平台；
- 旅程多节点（延时、条件、Webhook、派单）；
- Doris Bitmap 性能优化到亿级 3s；
- 画像前端升级（搜索、血缘）；
- 数据质量 DQC 完善。

## 5. 第 3 期（W17–W24）

- Lookalike 扩量；
- 推荐召回（协同 + 向量）；
- 价格带预测；
- MTA 归因；
- SDR 智能派单；
- 全面权限（字段级、数据域）与审计；
- 合规审计一轮通过。

### 6.1 协作机制
- **双周迭代**：Sprint Planning / Daily Standup / Review / Retro。
- **周会**：跨组协同、里程碑进度。
- **月度**：业务复盘、技术分享。
- **工具**：Jira（任务）、GitLab（代码）、飞书（沟通）、Confluence（文档）。

| 人员流动 | 中 | 中 | 文档归档；多人掌握关键模块 |
| 第三方通道封控 | 中 | 中 | 多供应商；内容合规审核 |

## 9. 验收与交付

- MVP 验收：所有 P0 功能通过 UAT，运营方可独立闭环。
- 智能化验收：意向评分 AUC ≥ 0.80，SDR 有效外呼率 +50%。
- 扩量验收：Lookalike 投放 ROI ≥ 直投；MTA 可用。
- 文档交付：10 份项目文档 + 运维手册 + 培训视频。

## 10. 变更与沟通

- 需求变更：CR 流程（PM + 架构 + QA 评审）。
- 风险上报：Risk Register；周会同步。
- 沟通矩阵：
  - 高管周报（PM）；
  - 跨部门月报（PM + 运营）；
  - 内部双周 Demo（研发 + 产品）。
