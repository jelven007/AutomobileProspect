# 产品方案（PRD）

> 文档编号：PRD-LeadOps-001　　版本：v1.0　　日期：2026-10-04　　负责人：张路

## 1. 产品定位

**一句话定位**：面向汽车销售公司的"数据 + 算法 + 运营"一体化潜客运营平台（CDP + MA + BI），帮助从亿级潜客中挖出高意向，自动化触达并精准派单。

**价值主张**：
- 对管理层：ROI 可视、决策有据。
- 对运营：高效圈人、自动触达、A/B 迭代。
- 对销售：优质线索、推荐话术、省力增产。
- 对合规：隐私可控、全链路审计。

## 2. 产品形态

- Web 后台：运营工作台、销售工作台、经营看板、管理后台。
- 开放 API：供广告投放、CRM、门店系统集成。
- 事件 Webhook：高意向触发等事件回推。
- SDK：Java / Python / Go。

## 4. 关键流程

### 4.1 运营圈人到触达
1. 进入"运营工作台 → 人群圈选"。
2. 拖拽条件（标签/事件/时间窗），实时预估人数。
3. 保存人群包 → 关联旅程或直接触达。
4. 编排旅程（SMS → 等待 → 企微 → 派单）。
5. 发布 → 系统灰度 → 全量。
6. 回到"洞察 → 漏斗"查看效果。

### 4.2 销售跟进
1. 销售登录看"今日线索池"。
2. 点开客户 360：标签、意向分、推荐话术、历史触达。
3. 外呼并记录结果（到店/无应答/无效/成交）。
4. 系统根据结果自动调度下一步。

### 4.3 投放扩量
1. 市场投放选"种子人群"。
2. 系统 Lookalike 扩量。
3. 推送至巨量/腾讯 DMP。
4. 回传曝光/点击/留资 → 归因 → 优化出价。

## 5. 关键页面与交互

### 5.1 人群圈选
- 左侧：标签树（支持搜索）。
- 中间：条件构造器（嵌套 AND/OR/NOT、时间窗、事件次数）。
- 右侧：预估人数（秒级）、历史记录、保存/导出。
- 兜底：SQL 模式（权限管控）。

### 5.2 旅程编排
- 拖拽画布（节点：发送、等待、条件、A/B、Webhook、派单）。
- 节点属性右侧抽屉编辑。
- 支持草稿、模拟运行、灰度发布。
- 节点实时数据展示：进入人数、成功率、转化率。

### 5.3 客户 360
- 顶部基础信息（含标签芯片）。
- 中部：意向分 + Top 原因（SHAP）、推荐车型。
- 下部：行为流水、触达历史、跟进记录。
- 行动区：立即触达、添加任务、推荐话术。

### 5.4 经营大屏
- 核心四格：今日线索 / 高意向 / 到店 / 成交。
- 转化漏斗（下钻战区/车型）。
- 实时触达趋势、ROI。
- 异常告警区。

## 6. UI/UX 约束

- 色彩：主色品牌绿、辅助蓝；状态色统一（成功绿、警告黄、错误红）。
- 栅格：12 栅，内容区最大 1440px。
- 字体：PingFang SC / 系统默认；正文 14px，标题 16/20px。
- 可访问性：WCAG 2.1 AA；对比度 ≥ 4.5；键盘可达。
- 响应式：1280 起步，支持 1920 大屏。
- 空状态与错误态必须有引导文案与行动按钮。

## 7. 权限与数据域

- 运营：全部数据域；标签管理需审批。
- 销售：仅本辖区客户；无 PII 明文权限。
- 店长：辖区看板 + 派单权限。
- 分析师：全部查询权限，无触达权限。
- 管理员：平台配置 + 审计日志。

## 8. 国际化与多租户

- 一期中文、单租户。
- 二期支持多语言、多品牌隔离（整车厂多子品牌场景）。

## 9. 指标体系（北极星 + 支撑指标）

- **北极星**：高意向线索贡献的成交 GMV 占比。
- **输入**：数据接入及时率、OneID 覆盖率、标签覆盖率。
- **过程**：圈人响应 P95、触达成功率、A/B 实验数量。
- **结果**：到店率、试驾率、成交率、ROI、单线索成本。

## 10. 发布策略

- 内测（2 周）→ 灰度（1 个月，1 个战区）→ 全量。
- 每次模型发布 Shadow Mode 7 天对比。
- 关键页面 A/B 发布，覆盖率先 5% → 50% → 100%。
