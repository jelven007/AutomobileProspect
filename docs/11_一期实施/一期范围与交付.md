# 一期范围与交付

> 文档编号：PM-LeadOps-P1-001　　版本：v1.0　　日期：2026-10-04　　负责人：张路

## 1. 一期定位

一期聚焦**潜客数据资产化**和**基础运营能力**，为后续圈选、模型、触达打地基。

> 产品形态：对象存储 → 数据同步与清洗 → 客户主数据库 → Web 客户管理

**不做**：OneID 多源打通、标签体系、意向评分、圈选引擎、旅程、A/B。这些在二期后展开。

## 2. 一期范围（P0 必做）

### 2.1 数据同步
- 从对象存储（S3 / OSS / TOS 之一）同步 **xlsx 格式**的用户数据
- 支持**手动触发**和**定时调度**（Airflow / cron）
- 单次任务可处理**亿级行**（分片 + 流式）
- **清洗规则**：
  - 丢弃第 1 列「所属户籍站」
  - 丢弃第 3 列「居住地址」
  - 丢弃最后两列
  - 第 4 列（编码编号）去除「2016户籍统计」前缀，仅保留数字
- 幂等 / 断点续传 / 失败重试
- 数据质量报告：读取行数、写入行数、丢弃行数、异常明细

### 2.2 客户主数据
- 建立客户主表 `customer`，字段参照 [数据同步与清洗规则](./数据同步与清洗规则.md#2-字段映射)
- 主键：`customer_id`（系统生成，雪花 ID）
- 业务唯一键：`huji_no`（编码编号去前缀后的纯数字）
- 支持软删除、乐观锁、变更审计

### 2.3 Web 客户管理（CRUD）
参照 [客户 CRUD 功能说明](./客户CRUD功能说明.md)：
- 列表 + 分页 + 多条件搜索（姓名、编码编号、性别、年龄段、城市）
- 详情页
- 新增 / 编辑 / 删除（软删除）
- 批量导入 xlsx（走同一套清洗管线）
- 批量导出 csv / xlsx

### 2.4 基础运维
- 任务管理页：查看同步任务状态、历史、重跑
- 日志与审计
- 简单权限：admin / operator / viewer

## 3. 一期不做（P2 推迟）

| 项 | 推迟到 | 原因 |
|---|---|---|
| 多源 OneID 打通 | 二期 | 一期只接 1 份数据源 |
| 标签 / 意向评分 | 二期 | 依赖二期算法 |
| 圈选 / 旅程 / A/B | 三期 | 依赖二期 |
| 大屏 | 二期 | 一期先把数据存进去 |
| 触达渠道（短信/企微） | 二期 | 一期不触达 |

## 4. 排期（6 周）

| 周 | 工作项 | 负责 | 交付 |
|---|---|---|---|
| W1 | 对象存储接入、xlsx 解析 PoC、表结构定稿 | 后端 + 数据 | PoC Demo、DDL |
| W2 | 同步服务 v1（单文件全量） | 后端 + 数据 | ingest-service MVP |
| W3 | 清洗流水线 + 幂等写入 + 质量报告 | 数据 | 可处理 100 万行 |
| W3–W4 | BFF `customer` CRUD API | 后端 | OpenAPI + Swagger |
| W4 | Web 列表 + 搜索 + 详情 | 前端 | Admin 工作台 /customer |
| W5 | 新增 / 编辑 / 删除 / 批量导入 / 导出 | 前端 + 后端 | 功能完整 |
| W5 | 亿级压测（分片 + 流式）| 数据 + SRE | 性能报告 |
| W6 | UAT、权限、审计、文档交付 | 全员 | 上线 |

## 5. 技术选型（一期收敛版）

| 层 | 一期选型 | 备注 |
|---|---|---|
| 对象存储 | S3 兼容（AWS S3 / 阿里云 OSS / 火山 TOS） | 通过 S3 SDK 适配 |
| 同步 / 清洗 | Node.js 流式 + exceljs/xlsx-stream-reader | 简单可控；二期可换 Spark |
| 调度 | 内置 cron（后期切 Airflow） | 一期不引入 Airflow |
| 存储 | PostgreSQL 15（分区表） | 亿级靠月分区 + 索引；二期上 Doris |
| 后端 | NestJS + Fastify + Prisma | 复用现有 BFF |
| 前端 | React + Ant Design + TanStack Query | 复用 admin 应用 |
| 导入导出 | exceljs（服务端） | 导出走异步任务 |

## 6. 一期验收标准

- [ ] 单份 1 亿行 xlsx 可完整落库，耗时 ≤ 4 小时
- [ ] 清洗规则 4 条全部通过单元测试覆盖
- [ ] 列表页 1 千万数据滚动翻页 P95 ≤ 500 ms
- [ ] 新增 / 编辑 / 删除接口 P95 ≤ 200 ms
- [ ] 批量导入 1 万行 ≤ 60 s
- [ ] 覆盖率：核心清洗与 CRUD 单测 ≥ 80%
- [ ] 一键重跑同步任务，重复数据不重入库

## 7. 风险

| 风险 | 影响 | 应对 |
|---|---|---|
| xlsx 表头跟预期不符 | 高 | 字段映射走 **yaml schema**，不写死 |
| 单文件过大 OOM | 高 | 使用流式解析，禁止全内存加载 |
| 编码编号重复 | 中 | 冲突走更新；审计记录来源文件与行号 |
| 清洗规则后续变更 | 中 | 清洗规则做成可插拔 pipeline |
