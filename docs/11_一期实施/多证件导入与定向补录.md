# 多证件导入与定向补录（2026-10-05，流水线 v6）

本说明取代历史文档中关于“编码唯一”“仅接受居民身份证”和“入库自动脱敏”的描述。编码编号仅供展示，导入仍提取数字，不因含非数字字符拒绝客户；手工编辑保留数字限制。证件与手机号延续现有明文存储规则。

## 证件规则

| `id_type` | 类型 | 清洗与准入 |
|---|---|---|
| `resident_id` | 居民身份证 | 保留 15 位扩展、17 位补校验位、非法日期向前修正并重算校验位；有效号码外侧的一对 `#` 自动去除。原有错误校验位仍仅告警 |
| `organization_code` | 组织机构代码 | 8 位主体 + 1 位校验位，兼容标准连字符、全角字符，按 GB 11714 校验后存储为 9 位 |
| `credit_code` | 统一社会信用代码 | 18 位限定字符，按 GB 32100 校验位检查 |
| `passport_cn` | 中国普通护照 | `G/E + 8 位数字`，或 `E + 合法字母 + 7 位数字` |
| `hk_macao_permit` | 往来港澳通行证 | `C + 8 位数字`，或 `C + 合法字母 + 7 位数字` |
| `mainland_permit` | 港澳居民来往内地通行证 | `H/M + 8 位数字`；历史号码末尾附带的 2 位换证次数移除并告警 |
| `taiwan_permit` | 台湾居民来往大陆通行证 | 8 位数字，必须明确提供证件类型 |
| `hongkong_id` | 香港居民身份证 | 1–2 位字母 + 6 位数字 + 括号校验位；按香港身份证加权规则校验，统一存储为半角括号格式 |
| `pending_document` | 证件类型待核实 | 仅限号码同时通过两种既有类型校验且明确指定此类型时使用；不得用于放行任意无效号码 |

- 导入识别「证件类型／证件种类／身份证件类型」列；支持以上类型代码或中文名称（也支持身份证、护照、回乡证、台胞证别名）。未提供时按明确格式识别。
- 当号码同时符合组织代码和护照/回乡证时，不猜测类型，返回 `ambiguous_document_type`。原始组织机构代码中的标准连字符可以消除歧义；人工确认仍无法定类时可明确标记 `pending_document`，并产生 `document_type_pending_verification` 告警。
- 带配对括号的香港身份证可自动识别；明确指定 `hongkong_id` 时也接受无括号输入，校验成功后统一补回括号。缺括号、括号不配对或校验位错误均拒绝。
- 为兼容存量，有效居民身份证默认保留居民身份证类型。纯数字信用代码若也符合居民身份证日期结构，须明确指定 `credit_code`。
- `NULL`、未知、手机号、含糊的短号、不支持的证件格式、无效组织代码/信用代码继续拒绝。外国护照、军官证等格式未在本版自动放行。
- 仅居民身份证推导出生日期、性别、省市区；其他证件只保留文件明确提供的这些字段。
- 常见告警：`id_card_hash_wrapper_removed`、`document_issue_suffix_removed`、原有 `id_card_birth_date_corrected` 和居民身份证校验位/行政区划告警。
- `invalid_id_card_format` 保留为兼容错误码，v5 含义为证件格式或校验位无效；`unsupported_document_type` 表示类型不支持。

证件格式依据：[国家移民管理局](https://www.nia.gov.cn/n741440/n741547/c1197066/content.html)、[回乡证终身号码说明](https://www.locpg.hk/fuzn/2013-03/05/c_125939266.htm)。这里只做格式与校验位检查，不代表证件真实性或有效期核验。

## 唯一性与接口

- 数据库全局身份映射主键为 `(id_type, id_card)`，分区内有效客户唯一索引为 `(id_type, id_card, ingest_month)`。
- 历史客户和身份映射统一默认 `resident_id`，迁移不删除、归并或重新解释存量数据。
- 普通导入按批次保留同类型同号码的最后一行；跨批次命中后更新。姓名覆盖，其他字段非空才覆盖，版本加一。统计时间仍不用于决定覆盖先后。
- BFF、对象存储导入、手工创建/编辑共享规范化规则和证件锁；来源行幂等键仍为 `(ingest_batch, source_file, source_row)`。
- 客户 API 保留 `id_card` 字段并新增 `id_type`。手工创建可自动识别，编辑省略类型时保留原类型；改变类型也检查目标身份冲突。
- 列表、编辑表单及导出 Excel 均包含证件类型；导出中文类型可再导入。

## 数据库升级

先停止导入和其他写入，保存数据库结构备份。已有 004 的数据库先执行 005；已有 005 的数据库只执行 006：

```sh
pnpm --filter @leadops/ingest-service db:migrate:documents
pnpm --filter @leadops/ingest-service db:migrate:hongkong
pnpm --filter @leadops/bff exec prisma generate
pnpm --filter @leadops/ingest-service build
pnpm --filter @leadops/bff build
```

迁移 005 在事务中持有表锁并重建唯一索引，大表执行期间需要维护窗口。迁移 006 仅扩展证件类型约束，先以 `NOT VALID` 提交再校验，不重建索引或改写客户数据。空库初始化命令 `db:migrate` 已包含 005 和 006。
